# Compton Effect Lab

A web app with lab materials for the Compton effect physics lab at PDTU.

## Technologies Used

### Core Framework & Build Tool
- **[React 19](https://react.dev/)** — UI component library
- **[Vite 6](https://vite.dev/)** — fast development server and bundler

### Routing
- **[React Router v7](https://reactrouter.com/)** — client-side routing (`react-router`, `react-router-dom`)

### Styling
- **[Tailwind CSS v4](https://tailwindcss.com/)** — utility-first CSS framework (integrated via `@tailwindcss/vite`)

### Animation
- **[Framer Motion v12](https://www.framer.com/motion/)** — declarative animations and transitions for React

### Charts & Data Visualisation
- **[Recharts v2](https://recharts.org/)** — composable charting library built on React and D3

### Code Quality
- **[ESLint 9](https://eslint.org/)** — JavaScript/JSX linter (`eslint`, `eslint-plugin-react-hooks`, `eslint-plugin-react-refresh`)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Lint source files
npm run lint
```
